# Dashboard for visualising DIALS A/B testing

## Prerequisites

Before starting ensure the following are installed:

- Python 3.10+
- Node.js and npm

## Configuration

Copy the example `.env` file, open and add in the workspace for your run data:

```bash
cp .env.copy .env
```

## Setup and run

Then you can run the setup script to start up the dashboard

```bash
chmod +x setup.sh
./setup.sh
```
